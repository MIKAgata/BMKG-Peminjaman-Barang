### Cara 1: Melalui Antarmuka Web (UI Aplikasi)                                                                                                         
                                                                                                                                                          
  #### A. Mengganti Kata Sandi Akun Sendiri (Admin atau Pegawai)                                                                                          
                                                                                                                                                          
  Setiap pengguna yang sedang login dapat mengganti kata sandinya sendiri:                                                                                
                                                                                                                                                          
  1. Klik nama akun di pojok kanan atas navbar -> pilih Profil Saya (atau buka /accounts/profile/).                                                       
  2. Klik tombol Ganti Kata Sandi (atau langsung akses /accounts/password-change/ http://127.0.0.1:8000/accounts/password-change/).                       
  3. Masukkan kata sandi lama dan kata sandi baru.                                                                                                        
                                                                                                                                                          
  #### B. Admin Mengubah Kredensial / Reset Kata Sandi Pegawai Lain                                                                                       
                                                                                                                                                          
  Administrator memiliki wewenang penuh untuk mengubah username, email, nama, peran, maupun mereset kata sandi pegawai:                                   
                                                                                                                                                          
  1. Login sebagai Admin.                                                                                                                                 
  2. Masuk ke menu sidebar Data Pegawai / Pengguna (URL: /accounts/users/ http://127.0.0.1:8000/accounts/users/).                                         
  3. Klik tombol Ubah (Ikon Pensil) pada baris akun yang ingin diubah.                                                                                    
  4. Di formulir pengeditan:                                                                                                                              
      • Anda dapat mengganti Username, NIP, Unit Kerja, Nama, dsb.                                                                                        
      • Pada kolom Reset Kata Sandi Baru (Opsional), masukkan kata sandi baru yang diinginkan (kosongkan jika tidak ingin mengubah kata sandi).           
  5. Klik Simpan Perubahan.                                                                                                                               
  ──────                                                                                                                                                  
  ### Cara 2: Melalui Terminal / CLI (Command Line)
  
  Jika Anda lupa kata sandi admin atau ingin menggantinya langsung dari server:
  
  #### Mengganti Kata Sandi via changepassword:
  
  Jalankan perintah berikut di root folder proyek:
  
    venv/bin/python manage.py changepassword <username>
  
  Contoh untuk akun admin:
  
    venv/bin/python manage.py changepassword admin
  
  Contoh untuk pegawai:
  
    venv/bin/python manage.py changepassword pegawai_andi
  
  Sistem akan meminta Anda mengetikkan kata sandi baru secara interaktif.
  
  #### Membuat Akun Superuser Baru:
  
    venv/bin/python manage.py createsuperuser
